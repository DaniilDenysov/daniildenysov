## 👋 About Me

I'm a **Unity Game Developer based in Warsaw**, focused on building complete, maintainable game systems rather than isolated features.

I work across **gameplay, multiplayer, tools, editor extensions, UI, shaders/VFX, AI and architecture**, and I've shipped projects to **Android, iOS, WebGL, VR and PC**.

- 🎮 Founder & Lead Unity Developer at **Cenoir Studios**
- 🛠️ Creator and maintainer of **MyToolz**, an open-source modular Unity framework
- 🌐 Commercial Unity work across **WebGL, mobile and VR**
- 🧱 Strong focus on **SOLID, modular architecture, reusable systems and clean tooling**
- 🚀 Experience leading technical work in multidisciplinary teams under real production deadlines
- 📦 Four published Google Play titles, multiplayer projects and browser-playable WebGL games

## 🚀 Featured Work

### 🧰 [MyToolz](https://github.com/DaniilDenysov/MyToolz)
Open-source modular tooling and systems for Unity, distributed as independent packages.

**Highlights**
- 30+ reusable systems and utilities
- Event Bus, MVP, Object Pooling, State Machines and Command Pipeline
- Input, loading, notifications, UI and inventory systems
- Audio, save/load, tweening and editor tooling
- Multi-threaded A* pathfinding
- CI/CD and package-oriented project structure
- MIT licensed

### 🎯 NoSaints
Online multiplayer FPS developed as a team project with me serving as **Tech Lead**.

**My work included**
- Modular game architecture
- Multiplayer implementation with **Mirror**
- Combat and game-mode flow
- UI and sound systems
- Shader Graph and VFX
- Technical coordination across a multidisciplinary team

### 🌒 NoSaints: Blue Whale
A dark single-player FPS currently being developed at **Cenoir Studios**.

I'm responsible for major parts of the technical direction, including the FPS foundation, gameplay systems, AI, UI, VFX, narrative tooling integrations and internal development standards.

### 🛰️ Salvager
Rogue-like project developed with a larger student team, where I worked as **Technical Lead**.

Notable engineering work included:
- Modular gameplay architecture
- Custom behavior-tree AI with editor tooling
- Environment and gameplay systems
- Inventory optimization from **O(n⁵) to O(n²)**
- Mentoring developers on Unity fundamentals
